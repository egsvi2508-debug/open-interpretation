# Open Interpretation (prototype)

Clickable prototype for a Project Slam idea: one open page per piece, with interpretations pinned to the bars of the score. Example: Prokofiev, Piano Sonata No. 4, Op. 29.

Analysis is summarised from Soyoung Cho, *Prokofiev's Piano Sonata No. 4 … A Performance Guide* (DMA diss., University of North Texas, 2023) and credited throughout. Score images: first edition (Gutheil / Breitkopf & Härtel), public domain, via IMSLP. All user names, comments and vote counts are invented examples.
